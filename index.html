02

Unified Cross-Platform Sentiment Analysis via Attention-Based Feature Fusion

Under Review · 2026

Proposes Cross-Platform Multi-Modal Opinion Mining, a framework that aggregates user-generated content from platforms like Instagram, Amazon, and Reddit to capture sentiment more holistically than single-platform, text-only approaches. Uses a transformer-based RoBERTa model for context-aware text feature extraction, platform-specific representations, and a cross-platform attention mechanism to fuse features before classification via a neural network. Evaluated on an 80-20 train-test split, the framework achieved 79.6% accuracy with balanced precision, recall, and F1 scores across sentiment classes — showing strong robustness to noisy, real-world data. The framework is designed to extend beyond text to images and video in future work.
